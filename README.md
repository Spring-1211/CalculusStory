# CalculusStory｜高等数学B故事册

> 同济《高等数学》第八版配套讲义：不只讲结论，更讲问题、思想、动机与用处。

## 这是什么

同济教材的优点是体系成熟、逻辑严谨、计算训练充分；它的叙述通常从现代定义直接开始，读者却不一定能看见“为什么需要这个概念”。本仓库是与教材并行使用的补充讲义，不替代教材，也不重抄教材公式。

“故事册”不是数学轶事集。这里的故事指一条可追问的思想链：当时有什么问题，已有工具为什么不够，数学家做了什么抽象，后来这个抽象又解决了什么。

每一小节从问题开始，并追问同一条思考链：

1. 历史上，数学家面对的原始问题是什么？
2. 不引入这个概念，推理会卡在哪里？
3. 现代定义为什么写成现在这样？它保留和舍弃了什么？
4. 这个概念在后续理论、物理、工程和计算机中有什么用？

每篇文章还明确列出：本节要解决的问题、学生最容易卡住的难点、理解检查题和可迁移的例子。

## 阅读方式

- 先按同济第八版的章节顺序阅读，再回到课本做计算训练。
- 每篇先读“原始动机”和“定义设计”，再看公式；把公式当成解决问题的工具，而不是起点。
- 课堂作业优先做概念辨析、构造例子和解释“为什么”的题目。
- 文中标注“待补”的文章是目录占位，不代表该节已经完成。

## 与同济第八版的对应关系

本仓库按“章—节—概念”建立文件，不把补充文章伪装成教材原文。第一章目前按出版社公布的第八版目录对齐：映射与函数、数列的极限、函数的极限、无穷小与无穷大、极限运算法则、极限存在准则与两个重要极限、无穷小的比较、函数的连续性与间断点、连续函数的运算与初等函数的连续性、闭区间上连续函数的性质。

同济第八版上册包括函数与极限、导数与微分、微分中值定理与导数的应用、不定积分、定积分及其应用、微分方程；下册目录会在对应教材版本确认后继续补齐。出版社书目信息见：[高等数学第八版上册](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=62cdab46938b7cc2960eedb1)。

## 固定写作模板

每个概念文章使用七个板块：

1. 历史来源：概念如何出现、哪些问题推动了它的变化。
2. 原始动机：不引入它会遇到什么具体麻烦。
3. 现代定义：给出必要的标准表述，避免大段照录教材。
4. 定义设计：解释域、陪域、条件和取舍。
5. 用处：理论内部的依赖，以及现实中的使用场景。
6. 典型误区：学生最容易把什么混在一起。
7. 思考题：要求构造、辨析、解释和迁移，不以重复计算为主。

模板文件：[templates/concept.md](templates/concept.md)。

## 网页入口

仓库根目录的 `index.html` 是无需构建的静态阅读入口；`concepts/` 中的页面对应单篇概念文章，适合课堂投影和学生课后阅读。部署到 GitHub Pages 后，每个小节都可以拥有独立链接。

当前 MVP 还提供六个知识库模块：

- [知识点图谱](graph.html)：D3 绘制前置、后继和同主题关系，点击节点进入知识点页。
- [数学家人物库](people.html)：人物思想与教材节点双向关联。
- [配套习题](exercises.html)：题目、提示、参考答案与知识点标签。
- [Lean4 形式化映射](formalization.html)：自然语言陈述、代码、mathlib 参考和验证状态。
- [思想时间线](timeline.html)：把人物、问题和知识点放回历史进程。
- [AI 数学辅助](ai.html)：围绕当前知识点生成可复制、带史实和验证边界的提示词，不部署重模型。

数据与页面分离，见 [data/README.md](data/README.md)；开源资源入口见 [复用资源清单](open-resources.html)。

知识图谱、人物、习题、形式化映射和时间线都使用可审阅的 JSON。提交前可运行 `node scripts/validate-data.mjs` 检查 ID、关系端点和双向引用；GitHub Actions 会自动执行同样的静态检查。Lean 代码的状态必须以实际编译为准，页面中的“教学占位”不会冒充已验证证明。

## 写作原则

- 历史服务于理解，不堆砌人物轶事；史实不确定时明确写出不确定性。
- 示例优先短小、可画图、能暴露定义中的边界。
- 公式只保留理解所必需的部分，计算训练回到同济教材。
- 图形优先使用可编辑的 SVG，并提供文字说明和替代文本。
- 所有外部事实和历史叙述附参考来源；教材内容只做短摘录或改写。
