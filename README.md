# 同济高等数学：动机与概念溯源

> 同济《高等数学》第八版配套讲义：补全每个概念的历史、动机、意义与应用。

## 这是什么

同济教材的优点是体系成熟、逻辑严谨、计算训练充分；它的叙述通常从现代定义直接开始，读者却不一定能看见“为什么需要这个概念”。本仓库是与教材并行使用的补充讲义，不替代教材，也不重抄教材公式。

每篇文章都追问同一条思考链：

1. 历史上，数学家面对的原始问题是什么？
2. 不引入这个概念，推理会卡在哪里？
3. 现代定义为什么写成现在这样？它保留和舍弃了什么？
4. 这个概念在后续理论、物理、工程和计算机中有什么用？

## 阅读方式

- 先按同济第八版的章节顺序阅读，再回到课本做计算训练。
- 每篇先读“原始动机”和“定义设计”，再看公式；把公式当成解决问题的工具，而不是起点。
- 课堂作业优先做概念辨析、构造例子和解释“为什么”的题目。
- 文中标注“待补”的文章是目录占位，不代表该节已经完成。

## 与同济第八版的对应关系

本仓库按“章—节—概念”建立文件，不把补充文章伪装成教材原文。第一章目前按出版社公布的第八版目录对齐：映射与函数、数列的极限、函数的极限、无穷小与无穷大、极限运算法则、极限存在准则与两个重要极限、无穷小的比较、函数的连续性与间断点、连续函数的运算与初等函数的连续性、闭区间上连续函数的性质。

同济第八版上册包括函数与极限、导数与微分、微分中值定理与导数的应用、不定积分、定积分及其应用、微分方程；下册目录会在对应教材版本确认后继续补齐。出版社书目信息见：[高等数学第八版上册](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=62cdab46938b7cc2960eedb1)。

## 固定写作模板

每个概念文章使用七个板块：

1. 历史来源：概念如何出现、哪些问题推动了它的变化。
2. 原始动机：不引入它会遇到什么具体麻烦。
3. 现代定义：给出必要的标准表述，避免大段照录教材。
4. 定义设计：解释域、陪域、条件和取舍。
5. 用处：理论内部的依赖，以及现实中的使用场景。
6. 典型误区：学生最容易把什么混在一起。
7. 思考题：要求构造、辨析、解释和迁移，不以重复计算为主。

模板文件：[templates/concept.md](templates/concept.md)。

## 写作原则

- 历史服务于理解，不堆砌人物轶事；史实不确定时明确写出不确定性。
- 示例优先短小、可画图、能暴露定义中的边界。
- 公式只保留理解所必需的部分，计算训练回到同济教材。
- 图形优先使用可编辑的 SVG，并提供文字说明和替代文本。
- 所有外部事实和历史叙述附参考来源；教材内容只做短摘录或改写。
