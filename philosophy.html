高等数学 B · 教学总纲

带学生重新发明数学

用自然的问题导向，还原概念从困境、猜想到定义和证明的生长过程。最终交付的不是零散知识点，而是一套可以带往未来的数学思考方式。

高度一

为什么教

知识会忘，思维方式留下来

高等数学的长期价值，不只在于记住极限、导数和积分，更在于面对陌生问题时，能够提出问题、区分猜想与证明、寻找反例，并把未知归约为已知。

课程追求真、善、美：真，是实事求是；善，是看见学生并帮助他们成长；美，是体会定义、证明和结构中的简洁与统一。AI 能帮助计算和检索，却不能替代真正的问题意识、批判创造与数学审美。

高度二

教什么

从被动接收，走向主动创造

先看懂大结构和核心问题，再把定义讲透、例子做足，最终做到会算、会用、能证明。无论学生想深入数学，还是把数学当作专业工具，都应带走四种长期能力。

可迁移思维把概念背后的判断标准迁移到新问题。

批判与创造提出猜想，寻找边界，知道结论的条件。

驾驭 AI善用工具生成候选方案，并用定义与证明复核。

数学审美欣赏好定义如何消除歧义，好证明如何以简驭繁。

高度三

怎么教

把成品倒放回问题

教材呈现的是整理后的书写逻辑，课堂要补回真实的思考逻辑：旧方法为什么失效？新概念必须保护什么？哪些直觉经不起反例？证明又是怎样从卡点中长出来的？

一个概念的五步

动机 → 直觉漏洞 → 严格定义 → 几何直观 → 边界测试

一节课的九步

复习 → 抛问题 → 失效 → 猜想 → 造法则 → 证明 → 回解 → 提炼 → 复盘

高度四

这门课

沿一条主线，读厚也读薄

实数 → 极限 → 连续 → 导数 → 积分 → 微分方程与级数

每个主题都沿“现象—定义—注释—几何—例子—性质”展开。先读厚，理解来龙去脉和条件边界；再读薄，看见左右、点与区间、局部与整体之间反复出现的统一结构。

高度五

更大的图景

让内容成为可连接的课程基础设施

理念提供方向，知识图谱提供骨架，讲义仓库承载内容，Lean4 路线图呈现“未证不可用”的高阶实例。教学 PPT、人物史、习题和 AI 辅助都围绕同一条教材主线互相引用，而不是彼此割裂的功能堆叠。

教师立场

入乎其内，出乎其外

实事求是，同一立场向内反思，看见学生，教学相长，守“未证不可用”。既理解定义和证明的细节，也把思想迁移到物理、工程、计算机、AI 和新的数学问题。

  1. 自然问题导向
  2. 重新发明数学
  3. 讲透来龙去脉
  4. 直观与严格并重
  5. 对立统一
  6. 读厚也读薄
  7. 教学相长
  8. 实事求是

每一节的最后一步

不是记住，而是复盘

溯源三问

它要解决什么问题？不这样定义会卡在哪里？定义保留和舍弃了什么？

批判三问

结论需要哪些条件？能否构造反例？这个思想还能迁移到哪里？
